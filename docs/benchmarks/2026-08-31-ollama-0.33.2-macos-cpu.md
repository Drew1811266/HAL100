# Ollama 0.33.2 macOS CPU 真实验收

日期：2026-08-31

## 验收边界

- 原生宿主：macOS / aarch64 / CPU，Apple M1，16 GiB 统一内存。
- 引擎：官方 Ollama `0.33.2`，隔离运行时只监听 `127.0.0.1:11434`，关闭云端能力；Darwin 资产
  SHA-256 为 `5751e296a2cd545939bdd51b700de0c20d319f0e723c9d7f48bebb5ab0b731d4`。
- 模型：`Qwen3.5-2B-Q4_K_M.gguf`；文件 SHA-256 为
  `aaf42c8b7c3cab2bf3d69c355048d4a0ee9973d48f16c731c0520ee914699223`，仓库 revision 固定为
  `f6d5376be1edb4d416d56da11e5397a961aca8ae`。
- CPU 变体使用独立模型标签，Modelfile 固定 `num_ctx=4096` 与 `num_gpu=0`；服务 keep-alive 为
  10 分钟，避免并发验收波次之间卸载。

## 实际执行设备证明

HAL100 不以 `HAL100_OLLAMA_ACCELERATOR=cpu` 或宿主具备 CPU 作为运行时证据。资格请求完成且模型
仍驻留时，适配器通过官方 `/api/ps` 精确匹配同名模型，本次返回 `size_vram=0`；Ollama 调试日志
同时记录 `offloaded 0/25 layers to GPU`、`runner.vram="0 B"`。部署指纹把 `cpu` 加速器键与引擎
指纹和模型 ID 一同绑定，运行方案生命周期中的每次资格复验都要求实际观察仍与 CPU 支持格相符。
