## 交付范围

- 一级业务导航从八个入口收敛为：首页、模型与运行、软件接入、Agent、活动；设置保持独立。
- 建立 `/workspace/models`、`/workspace/runtime`、`/workspace/services`、`/workspace/test` 与 `/activity/*` 稳定路由。
- `/models`、`/backends`、`/test`、`/usage`、`/audit` 保留并重定向到新位置。
- 原推理后端页按展示职责拆为“运行”和“推理服务”，底层命令、管理器与确认边界不变。
- 建立 `UiStatus` 与首页摘要 ViewModel；正常首页只显示一份状态摘要、一个推荐主动作和按需技术详情。
- 提取 `AppShell`、`PageHeader`、`StatusSummary`、`DetailDrawer` 展示组件；组件不拥有 Rust 权限或领域策略。
- 外观入口只保留在设置；设置完成后不再显示初始化进度和环境准备总览。
- 首次设置仍保留下载源、登录启动、准备状态和完成动作的完整闭环。

## 架构与安全结论

- 界面入口合并没有合并 Rust 领域管理器、数据库所有权、凭据身份或一次性计划。
- `OverviewStatusView` 只返回状态、用户文案、推荐路由和非敏感详情，不返回路径、端口、凭据或日志正文。
- 推荐动作只是导航，不构成授权；安装、配置、移除和清理仍必须进入既有计划与原生确认链。
- 本轮不新增系统权限、后台轮询、Shell、Accessibility、Screen Recording 或 Apple Events。
