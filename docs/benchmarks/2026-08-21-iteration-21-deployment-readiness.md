## 安全结论

- Pi Agent Core没有获得Shell、包管理器、任意文件读写、Accessibility、Screen Recording、Apple Events或root Helper权限。
- 工具参数必须精确等于`{"target":"deployment","sampleCount":3}`；扩大样本、改变目标、请求日志或增加任意字段均由Rust与TypeBox共同拒绝。
- 观测窗口约200毫秒，每100毫秒响应任务取消；任务结束后不保留timer、不注册后台服务。
- 返回值不包含后端ID、目标ID、本地路径、配置正文、凭据、提示词、回答或日志正文。
- 观测结果不是授权令牌；可写操作继续要求一次性计划、Rust原生确认、现实状态复验、专用执行器、写后验证和失败回滚。

本迭代补齐部署前证据和瞬时运行状态。外部软件自动安装仍需后续版本化受管配方与供应链校验，不通过本轮能力绕过。
