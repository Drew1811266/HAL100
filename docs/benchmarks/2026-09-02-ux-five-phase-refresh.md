## 3. 真实界面验收

Chromium以1280×800和880×700为主要视口，覆盖：

- 配置后首页和首次使用首页；
- 添加模型抽屉；
- 云服务配置对话框；
- 快捷切换；
- 软件接入；
- Agent；
- 活动用量；
- 设置。

验收结果：

- 浏览器控制台0 error、0 warning；
- 880 px视口的根节点和页面宽度均为880 px，无横向溢出；
- 快捷切换的技术兼容信息与外部候选默认折叠；
- 880×700下Agent的任务位置、输入框、确认说明和主执行按钮同屏可见；
- 云服务配置对话框完整位于侧栏右侧，字段、提示和操作按钮均可见；
- 浏览器预览中的写操作保持禁用并明确说明，不产生模拟成功状态。

真实界面检查发现并修复两项问题：

1. 低高度窗口中Agent主执行按钮落在首屏下方；通过仅针对低高度的非核心说明压缩与单行状态摘要
   修复，未删除安全边界。
2. 880 px窗口中云服务对话框左侧被固定侧栏遮挡；通过将对话框遮罩限定到主工作区修复，最终
   对话框坐标为`x=252`、宽604 px，侧栏右边界为`x=228`。

`prototype/HAL100_UI_UX_OPTIMIZED.html`，因此不能将其判定为确认版视觉已经落地。本次纠偏以该HTML

- 软件接入改为单卡片五行状态列表；

- 活动改为三项摘要、14天柱状趋势与客户端构成，筛选和明细降级为按需展开；

## 8. Agent任务优先交互再设计

针对真实使用中“处理位置、推荐任务、运行详情和结果空状态同时争抢注意力”的问题，Agent页面进一步
收敛为一条可预测的任务路径：描述目标 → 分析并展示结果/计划 → 用户确认后执行。新任务默认不预填内容，
快捷任务只负责填充目标并自动聚焦输入框；本地/云端选择、云端范围和运行安全详情均改为按需展开，释放
模型入口移入运行与安全详情，避免与主执行按钮并列造成误操作。结果区增加三步进度提示与说明性空状态，
主操作按钮与输入框在视觉和键盘顺序上保持一致。

在桌面断点，任务卡与结果卡使用相同的 1:1 列轨道并拉伸到同一高度基线；进入窄窗口后自动切换单列，
避免卡片被压缩或出现横向滚动。

 Chromium与macOS原生窗口均完成真实交互复验：模板填充、输入聚焦、云端范围展开、空目标禁用、页面切换
滚动归零均符合预期；新版截图保存在`output/playwright/app-agent-task-first-redesign-v2.png`与
`output/playwright/app-agent-task-first-min-window.png`、`output/playwright/app-agent-equal-panels.png`。变更后Desktop 36项测试、Biome、TypeScript、
`pnpm check`及Tauri debug app bundle均通过。

## 9. 活动用量页信息密度优化

针对活动/用量页中“筛选区过高、Token构成与计量说明层级不清、表格首行与表头视觉叠压”的问题，
将页面收敛为“摘要 → 折线趋势/客户端 → 年度活动方格 → 按需展开的时间范围、筛选、构成与请求明细”三层阅读路径：

- 默认只展示最近14天摘要、趋势和客户端构成，筛选与明细通过明确的“筛选、时间范围与请求明细”折叠入口按需展开；
- 恢复 Token 折线趋势与过去365天请求活动方格：折线按年/月/周/天聚合并支持三类 Token 图例切换，方格按请求次数编码并可点击日期联动到单日小时趋势；
- Token构成与计量口径改为等宽双卡片，计量覆盖率提升为右侧主指标，并补充“当前请求中有精确计量值的比例”解释；
- 请求明细增加独立标题、当前结果条数和范围说明，表头使用不透明背景、行间分隔与状态胶囊，明细区域独立滚动，避免首行穿透表头；
- 筛选选择后显示已应用项数并作用于整页，清除筛选在无筛选时保持禁用，保持桌面与窄窗口的单列降级。

浏览器与macOS原生窗口均完成真实展开、滚动和筛选入口验收；证据截图保存在
`output/playwright/app-usage-refined-scrolled.png`。变更后Desktop 36项测试、Biome、文档一致性检查及
Tauri debug app bundle均通过。
