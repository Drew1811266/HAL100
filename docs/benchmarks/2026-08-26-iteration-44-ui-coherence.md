# 迭代44：全局界面层级与排版收口

- 日期：2026-08-26
- 范围：首页、模型库、运行、软件接入、Agent、用量、设置
- 边界：只调整前端信息层级、布局、样式与响应式规则；不改变RPC、数据库、Pi权限、受控执行或
  发行流程

## 基线问题

- 模型与运行、活动的同域子导航位于页面标题上方，页面身份层级不稳定。
- Agent页状态、技术详情、复合任务、输入与结果使用过多独立边框和不一致比例，复合任务主按钮
  在常用窗口宽度下形成大面积品牌色块。
- 页面内容宽度、普通卡片表面和低风险文字按钮缺少统一规则；用量工具栏回退为浏览器默认按钮
  样式。

## 实现结果

- 共享页面骨架统一为标题区在前、同域子导航在后；常规业务页使用1120 px内容上限，Agent使用
  1140 px。
- 页面背景、侧栏、卡片表面、边框和极轻阴影统一到同一组亮/暗色令牌；主要按钮、次级按钮和
  Text按钮补齐一致的对齐与交互状态。
- Agent状态摘要与技术详情组成连续卡片；复合任务区压缩为清晰字段和紧凑动作；输入与结果在
  1440 px并列，在1240 px以下单列，880 px下任务图字段继续安全降级。
- 首页、模型与运行、软件接入、活动和设置保留原有职责，仅收敛标题、卡片密度、留白和对齐。

## 浏览器验收

使用项目Node 24工具链和Playwright CLI连接正在运行的Vite开发服务器：

- 880 × 700：逐页检查7个现行入口，`document.documentElement.scrollWidth`均等于880，页面级
  横向溢出为0。
- 1200 × 900/1000：复核亮色Agent、活动、首页、模型库、运行、软件接入和设置，以及深色设置。
- 1440 × 1000：复核深色Agent双栏、复合任务紧凑动作、输入与空结果对齐。
- 所有回归页面的Playwright控制台错误为0。
