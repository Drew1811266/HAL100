## 开发进度

- 个人运行方案已升级为Rust掌权的持久化配置资产，支持保存、实时复验、一次性预检、原生确认、原子切换、切换后复验和重启补偿。
- 推理引擎边界扩展为14个适配器、29个“平台 × 架构 × 加速器 × 部署”支持格，并以版本化矩阵、七类证据、真实验收产物和审查账本区分架构接入与正式支持。
- Ollama CPU/Metal与MLX-LM Apple Silicon/Metal保持正式外部支持；vLLM、MLC LLM、OpenVINO、SGLang、LMDeploy和TensorRT-LLM完成软件适配与有界验收入口，但在对应真机证据完成前继续保持`connected`。
- Agent RPC升级到v13，覆盖20类任务和20个固定工具；运行方案启用进入Pi提案、Rust裁决、一次性计划、原生确认、确定性执行和现实复验链路。
- 运行方案成为独立一级入口；首页、模型与运行、Agent和运行方案页面继续统一信息层级、卡片节奏与响应式布局。
