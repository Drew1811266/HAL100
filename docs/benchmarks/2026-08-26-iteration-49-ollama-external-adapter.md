# 迭代49：外部Ollama只读适配器验收

- 日期：2026-08-26
- 范围：外部引擎只读边界、Ollama版本/模型目录、桌面能力目录、运行身份候选
- 非范围：Ollama安装与启停、模型拉取或删除、外部方案保存与激活、Windows/Linux桌面实现、
  发行流程

## 实现证据

- 协议层新增`ExternalEngineSnapshot`、有64位摘要的`ExternalEngineModelSummary`及无执行权的
  `ExternalRuntimeProfileCandidate`；序列化测试确认DTO不含命令、路径、API根地址或凭据。
- Infra新增对象安全的`ExternalInferenceEngineAdapter`，与拥有安装/移除/启停生命周期的托管
  适配器分离。首个Ollama实现固定访问`127.0.0.1:11434`的官方版本和模型目录端点，禁用代理，
  使用350毫秒连接/1秒总超时、64 KiB版本/4 MiB目录上限及4096模型上限。
- 模型目录严格要求名称字段一致、字符串有界、无控制字符、摘要为64位十六进制且名称不重复；
  目录无效时保留已验证的引擎版本身份，但明确标记目录不完整并拒绝生成方案候选。
- 桌面能力目录始终列出已注册的外部Ollama描述符；只有服务可达时附加实时快照。候选生成测试
  覆盖已保存、已启用、外部所有权、引擎一致和API根地址完全匹配，禁用、错引擎、错地址与目录
  不完整均故障关闭。
- 后端发现页显示可验证模型数量和有限模型摘要；运行方案页最多展示6项只读候选及短摘要，明确
  告知外部方案保存和切换尚未开放，并在940/700 px断点收敛为单列/左对齐布局。
- 日志测试临时目录加入进程内原子序号，消除并行测试在低分辨率系统时钟下撞名和相互清理的
  偶发风险；日志测试组连续20轮通过。

## 自动化结果

- 完整`pnpm check`通过：文档漂移、Biome、TypeScript、Desktop 26项、Agent Kernel 34项、
  Rust格式、全目标Clippy、Sidecar构建和默认Rust workspace测试全部绿灯。
- 默认Rust workspace执行342项：Core 54、Desktop Rust 96、Infra 136、Gateway端到端10、
  Platform 10、Protocol 32、共享协议夹具4；重型、联网和真实模型项继续按既有规则忽略。
- 新增Ollama适配器3项测试、外部DTO 2项测试和桌面候选组合1项测试全部通过；日志测试组额外
  连续运行20轮，无临时目录碰撞。
- `pnpm build`通过Desktop生产前端、Agent Kernel Sidecar和Rust workspace开发构建；
  `git diff --check`通过。

## 结论

HAL100现在能在不取得外部生命周期权限的前提下，如实回答“本机Ollama是什么版本、有哪些可
验证模型”，并把用户保存的连接意图与实时稳定摘要组合成未来运行方案的只读身份。当前仍没有
外部方案执行权；下一阶段应单独设计Ollama方案的版本化保存、漂移预检、一次性确认和失败恢复。
