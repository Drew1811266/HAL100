# 迭代45：首页与Agent关键任务层级校准

- 日期：2026-08-26
- 范围：首页首次设置/模型未准备状态，Agent就绪态、单任务工作台与闲置复合任务
- 边界：只调整React结构、CSS布局和响应式表现，不改变Pi能力、Rust授权、RPC、SQLite或发行范围

## 用户可见问题

- 首页状态标签被通用自动外边距推离标题，状态与推荐动作又使用两张大型卡片重复表达同一事项。
- Agent在用户截图的1159 px窗口过早转为单列，结果区退出首屏；边界、状态、复合任务和单任务
  使用近似权重连续堆叠，常用输入被高级任务挤压。
- 状态图标继承旧三行网格，状态卡被无意义拉高；复合任务字段、复选项与动作形成Z字跳跃。
- 单任务执行按钮位于推荐模板之后，用户需要先越过辅助内容才能执行已经写好的任务。

## 实现结果

- 首页合并为单一行动卡：状态标签、问题、合并后的精确说明和主动作位于同一主轴；系统详情与
  次级入口共用紧凑底栏。页面阅读宽度收至900 px。
- Agent工作台在1100 px以上使用0.9/1.1双栏，空结果保持410 px稳定高度并在同列滚动时可见；
  低于1100 px再转为单列。
- 闲置复合任务排在工作台后；活动、补偿或可恢复任务继续提升到工作台前。常用窗口中的两个
  选择字段与40 px创建动作同行，辅助复选项位于下一行。
- Agent运行主动作通过布局顺序前置到推荐模板之前；状态图标重置旧网格跨行，状态卡从106 px
  压缩到80 px，就绪提示与历史策略不再都使用胶囊背景。
