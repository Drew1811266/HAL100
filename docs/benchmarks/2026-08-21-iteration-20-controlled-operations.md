## 安全结论

- Pi Agent Core没有获得Shell、任意文件读写、Accessibility、Screen Recording、Apple Events、root Helper或长期后台轮询权限。
- Rust Tool Broker仍是唯一执行权威；Sidecar只能请求固定、强类型、可审计的能力。
- 运维历史不会向模型暴露目标ID、提示词、回答、本地路径、配置正文或凭据，Rust还会对返回标识执行二次校验。
- 四类外部Agent的检测彼此隔离；适配器内部错误被折叠为固定故障项，不泄露路径或原始错误正文。
- 修复只适用于未配置或需要刷新且可安全修复的状态；冲突、外部修改、不兼容和Blocked状态保持只读。
- 所有写操作继续要求Rust原生确认，并复用对应客户端的快照复验、备份、独立凭据、写后验证与失败回滚。

本迭代提高的是HAL100完成部署前检查、配置诊断、失败解释和受控修复的能力。未来若需要安装依赖、采集日志或短期监测，应继续添加按任务、按对象、按动作授权的Broker能力，不把广泛系统权限直接授予模型或Sidecar。
