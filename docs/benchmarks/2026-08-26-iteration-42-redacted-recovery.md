# 2026-08-26 迭代42：非授权恢复纵向验收

## 目标

允许开发版在应用重启后找回复合任务的语义形状，同时证明任何历史成功、计划、确认、执行或
补偿状态都不能成为新进程的授权。恢复不是继续旧任务，而是用户重新选择精确目标后从现实重验。

## 合同与实现

`v11-composite-recovery.json`固定9类语义：

- 非终态图以原子JSON写入，最大16KiB，Unix权限0600；
- 只包含schema、序列、图/节点枚举状态、任务/目标类别、成功谓词、依赖序号和枚举证据摘要；
- 模型ID、外部Agent ID、提示词、回答、plan/run ID、确认、参数、路径、凭据和原始结果均为0；
- 协议节点与顶层对象拒绝未知字段，文件过大、符号链接、非法JSON、未知字段或越界结构均拒绝；
- 新进程只暴露`recoverableTaskGraphCheckpoint`，不会安装为当前可执行图；
- 用户重新选择模型与软件后，Rust工厂重新构造精确定义并校验3/4节点语义形状；
- Core恢复将所有节点退回依赖派生的`ready/blocked`，证据、真实变更和重新授权标记全部清零；
- `succeeded`或`compensated`终态删除恢复文件。

## 纵向结果

持久化测试把3节点图推进到待确认后模拟进程重建。磁盘文件不含旧模型与OpenCode身份；新运行时
只有可恢复快照，没有当前图。4节点错形恢复被拒绝；用户重新选择另一精确模型与OpenClaw后，
同形状图恢复为全新现实重验证状态。随后三个节点均由新证据完成，终态文件被清理。

| 验收项 | 结果 |
| --- | ---: |
| v11恢复语义 | 9 / 9 |
| 文件大小上限 | 16KiB |
| 文件权限 | 0600 |
| 敏感或授权字段 | 0 |
| 未知字段接受 | 0 |
| 错误图形状接受 | 0 |
| 恢复旧成功/变更/授权 | 0 / 0 / 0 |
| 终态残留恢复文件 | 0 |

另有桌面服务测试覆盖公开恢复入口：取消后的脱敏形状可用新的用户选择重绑，检查点序列递增，
所有非根节点保持`blocked`且不带证据或授权。Agent页面会明确解释“旧成功、计划与确认均不恢复”。
