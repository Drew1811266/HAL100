## 交付边界

本次没有增加Agent权限或复制模型目录/下载系统。`RemoteModelCatalog`继续拥有远端响应、路径和元数据策略，`ModelDownloadManager`继续拥有仓库复验、可信哈希、空间、重复项、受管路径、下载状态、GGUF校验和原子安装。桌面Agent适配层只增加可取消等待、结果预算、细粒度安全错误码和确定性组合测试。

RPC v4当前的“最多4个必需工具、1个写计划”被明确为版本化单任务预算，不是代码量或产品能力上限。共享`v4-tools.json`现在同时描述128 KiB结果预算、13项工具顺序、读/计划效果、前置关系、原生确认以及参数正反例；Rust与TypeScript分别从自己的权威实现验证同一策略，运行时不依赖外部JSON文件。

本地模拟服务纵向测试不访问公网，完整执行：

1. 从数据库读取用户默认来源并搜索公开仓库。
2. 拒绝不在同任务搜索结果中的伪造仓库。
3. 检查精确仓库并只保留可信SHA-256 GGUF。
4. 拒绝不在同任务仓库快照中的伪造文件。
5. 生成外层一次性计划，模拟Rust原生确认后取出隐藏的底层计划。
6. 由同一个`ModelDownloadManager`下载本地模拟GGUF，完成SHA-256、GGUF校验、原子安装和模型索引。
