# 迭代46：个人运行方案与Pi受控切换验收

- 日期：2026-08-26
- 版本：1.0.4开发版
- 范围：运行方案数据合同、Rust切换管理器、Pi受控任务、桌面页面与响应式回归

## 实现结果

- `RuntimeProfileSpecV1`与SQLite schema v10保存无凭据的模型哈希、引擎版本和容量策略快照。
- `RuntimeProfileManager`提供保存、编辑、删除、准备度/漂移计算、5分钟一次性预检、执行前复验、
  成功快照更新和失败恢复原模型。
- 侧栏增加位于“活动”下方的“运行方案”一级入口；“模型与运行”保留模型、运行、推理服务三个
  技术子页。方案页宽窗口双列、940 px以下单列，支持多个方案和明确的可运行/需复验/需修复状态。
- Agent RPC v13增加第20类任务、第20项工具和第11种原生动作。Pi只能从脱敏目录选择精确
  `profileId`，最终由Rust原生确认和`RuntimeProfileRecheck`判定。
