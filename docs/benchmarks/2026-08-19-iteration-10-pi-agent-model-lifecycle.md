# HAL100 迭代10 Pi受控操作与模型生命周期验收

日期：2026-08-19
平台：macOS Apple Silicon（本机Apple M1 / 16 GiB）
状态：完成

## 1. 目标与结论

本迭代审计内嵌Pi内核是否真实、当前且可控，并补齐下一批产品能力。结论如下：

- HAL100真实使用`@earendil-works/pi-agent-core`与`@earendil-works/pi-ai` 0.84.2；版本与审计时上游主分支包版本一致，依赖由`package.json`和`pnpm-lock.yaml`精确锁定。
- HAL100没有嵌入完整`pi-coding-agent`，因此不会获得其`bash`、`read`、`write`、`edit`、扩展、Skills和上下文自动发现能力。这是产品安全边界，不是缺失安装。
- Pi只负责模型会话和工具循环。Sidecar中的工具都是RPC代理，Rust Tool Broker仍是参数、顺序、所有权、确认和执行的唯一权威。
- Agent RPC由v1升级到v2，产品工具由3个扩展到8个；模型启动/移除、llama.cpp安装/卸载与OpenCode配置都只能创建一次性计划。
- 模型页与Agent页已接入同一模型移除管理器：托管文件进系统废纸篓，外部文件只移除索引，活动模型和内置Agent模型拒绝移除。

Pi内核对当前已开放能力已经形成可运行闭环，但HAL100 Agent尚不是最终功能全集。模型搜索/下载、失败分片清理、强制切换、自包含Sidecar和正式平台沙箱仍是后续工作。

## 2. 当前8个工具

| 类别 | 工具 | 约束 |
| --- | --- | --- |
| 只读 | `hal100.inspect_system_summary` | Rust读取Apple Silicon硬件和模型目录空间摘要 |
| 只读 | `hal100.inspect_runtime_catalog` | Rust返回脱敏引擎、活动路由和模型目录 |
| 只读 | `hal100.inspect_opencode_status` | Rust检查OpenCode安装、配置和Provider所有权 |
| 计划 | `hal100.plan_model_start` | 必须先读取目录；精确modelId；不直接启动 |
| 计划 | `hal100.plan_model_removal` | 必须先读取目录；按所有权生成计划；内置模型拒绝 |
| 计划 | `hal100.plan_engine_install` | 固定目标`llama.cpp`与固定官方供应链 |
| 计划 | `hal100.plan_engine_remove` | 只卸载HAL100托管引擎，不删除模型 |
| 计划 | `hal100.plan_opencode_configuration` | 必须先检查状态；拒绝冲突Provider |

每个模型回合只暴露Rust判定的唯一下一工具；每项任务最多4次调用、最多1个写操作计划。Pi工具成功、模型文字同意和WebView状态都不构成授权。

## 3. 一次性操作计划

Rust保存公开Agent计划与底层确定性管理器计划的私有映射。底层计划ID不发送给Pi。计划具有以下共同属性：

- 绑定生成任务和精确目标；
- 5分钟有效；
- 只保留最新一项且只能消费一次；
- 新任务、取消、失败或取消原生确认会同步废弃；
- 执行前再次显示Rust原生确认，并重新验证目标状态。

模型删除还持有引擎生命周期锁，确保“确认模型未运行”与文件/索引操作之间不会插入模型启动。

## 4. 模型所有权与回收

`ModelRemovalManager`执行以下固定分支：

1. `managed`且文件存在：拒绝符号链接和越界路径，复核文件大小后使用`trash` 5.2.6移入系统废纸篓，再删除索引。
2. `managed`且文件缺失：复核仍然缺失，只清理失效索引。
3. `external`：不读取、移动或删除源文件，只删除HAL100索引。
4. 活动模型：拒绝。
5. 固定Qwen Agent模型：拒绝，防止Agent删除自身运行依赖。

审计只保存模型ID、所有权、移除类型等白名单摘要，不保存完整文件路径。

## 5. 自动与真实验收

本迭代执行并通过：

- Agent Kernel TypeScript类型检查与18项测试；
- React桌面类型检查与15项测试；
- Rust工作区编译；
- Desktop Agent 13项非真实模型测试；
- 模型移除4项专项测试：外部文件保留、托管文件模拟废纸篓、活动/越界/内置模型拒绝、失效索引清理；
- 真实本机Qwen3.5-2B保护验收。

真实保护验收耗时52.91秒。Pi先读取真实目录并提出删除内置Qwen模型的计划请求，Rust在计划阶段拒绝；验收随后确认GGUF文件仍存在、SQLite模型记录仍存在。测试没有调用任何真实删除或废纸篓操作。

迭代前的真实能力复核还包括：模型计划、硬件诊断与完整9场景验收通过；最近一次完整样本为`accuracy=9/9`，冷请求13.182秒，暖请求20.560/24.491/5.222秒，目录11.158秒，计划43.751秒，冷启动取消4毫秒，推理中取消56毫秒，空闲退出2.5秒。
