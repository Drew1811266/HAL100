# 迭代30：用量统计统一口径与交互收口

- 日期：2026-08-24
- 版本：1.0.2 后续开发线
- 结论：通过

## 统一数据协议

- `UsageScopeQuery`以本地自然时间范围、日序列范围、客户端、模型、后端、状态和明细上限为唯一查询输入。
- `UsageScopeSummary`一次返回同范围总量、已计量请求数、成功请求数、客户端分布、最近明细、日聚合和小时聚合。
- SQLite所有子查询复用同一过滤条件；请求总数与Token计量覆盖率分开表达，未返回usage的失败或取消请求不会被误算为0 Token的成功计量。
- `UsageFilterOptions`返回真实可选维度及最早/最近活动时间，用于范围导航边界和默认活动锚点；年度活动图固定保留365个可操作日期，无请求日按零请求呈现。

## 界面职责

- 时间粒度与前后导航控制整页；默认月份锚定最近活动日期。
- 趋势图回答三类计费Token随时间如何变化；未来点不进入折线，图例可切换，悬停/键盘聚焦可读取同一时间点三项值。
- 年度格子回答每天是否活跃及请求频率，并作为单日视图入口；颜色不编码Token。
- 摘要回答规模、请求成功情况、输入缓存效率和计量可信度；构成条回答三类Token比例；明细提供精确事件核对。
