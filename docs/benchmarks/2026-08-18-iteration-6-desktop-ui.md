# 迭代6标准化桌面界面验收

日期：2026-08-18
平台：Apple M1、16 GiB、macOS内部开发环境
范围：首次启动、通用客户端、设置、数据保留、审计、空/错/加载状态与隐藏窗口零轮询

## 1. 功能闭环

- 五步首次启动向导保存当前步骤，下载源必须由用户明确选择，随系统登录启动首次询问且默认关闭。
- OpenCode保留专属接入；通用OpenAI/Anthropic客户端可按显示名签发独立Key，明文只显示一次，Gateway无需重启即可认证或撤销。
- 设置页读取真实登录项和SQLite设置，Token默认保留90天、审计默认365天；保存策略不删除数据，用户确认“按策略清理”后才执行。
- 审计页按需读取最多200条事件，支持类型筛选、目标搜索和详情抽屉；详情只包含Rust固定白名单字段。
- 撤销客户端和清理过期数据均从Rust发起原生确认；清理预览与执行绑定相同截止时间和准确条数。

## 2. 界面验收

使用真实Vite页面在1280×800视口检查总览、软件接入、审计、设置和完整1—5步首次启动向导。所有页面标题、主要动作、禁用状态、空状态和安全说明均可见，浏览器控制台警告与错误为0。总览阶段状态已从陈旧的4/9修正为6/9。

浏览器预览保持只读，`?preview=onboarding`只用于开发视觉回归，不写Tauri设置或操作系统登录项。

## 3. 后台活动与资源

代码静态复核只发现一个前端`refetchInterval`：模型下载存在活动任务且窗口可见并聚焦时每500毫秒刷新。窗口`blur`、隐藏或任务结束后立即返回`false`；活动状态由浏览器事件更新，没有额外计时器。审计、统计、设置、硬件和接入页均不轮询，数据保留没有后台清理任务。

常驻开发进程在无模型推理时连续5次、间隔1秒CPU采样均为0.0%。`vmmap -summary`报告物理占用40.8 MiB、峰值43.3 MiB，低于后台80 MiB预算。
