## 冷启动缺陷与修复

首次使用未签名 debug `.app` 进行真实冷启动时，恢复页在 12 秒后显示 `startup_timeout`。根因不是 Core 或资源加载失败，而是启动标记依赖 `requestAnimationFrame`；Tauri 主窗口在原生初始化完成前保持隐藏，WebView 会暂停动画帧，因此页面已经挂载但无法声明就绪。

修复后由 React `useLayoutEffect` 在提交阶段声明界面就绪，不再依赖窗口可见性或动画帧。新增 `main.test.tsx` 回归，明确断言应用提交后调用就绪回调且不请求 animation frame。恢复页仍覆盖真实模块加载失败和真正的启动超时。
