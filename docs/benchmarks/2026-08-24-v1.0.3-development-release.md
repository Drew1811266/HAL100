## 版本边界

- 本版本继续作为早期开发进度标签，不包含签名、公证、安装包发售或正式发布流程。
- Root package、Desktop package、Agent Kernel Sidecar、Tauri 配置、Rust workspace 与 Cargo lock 中的 HAL100 自有包统一为 `1.0.3`。
- `v1.0.2` 保留为既有历史标签；1.0.3 使用新的提交与 `v1.0.3` 标签，不改写旧版本。

## 用量统计

- 桌面端与 SQLite 共用统一范围查询，年、月、周、天四档和客户端、模型、后端、状态筛选驱动同一份摘要、趋势、构成与明细。
- Token 趋势独立展示缓存命中的输入、缓存未命中的输入与输出，并只使用后端返回的精确 Usage 数据。
- 全年活动图固定展示过去 365 天，一个格子代表一天；点击日期进入单日范围，再次点击恢复此前范围。
- 查询范围切换复用上一帧数据，不再回退到整页加载状态；未来日期不绘制为零值。
- 操作记录窗口限制为最近 50 条，数据库历史仍由用户设置的本机保留策略管理。
