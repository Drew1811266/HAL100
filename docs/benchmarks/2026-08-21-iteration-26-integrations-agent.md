# 迭代26：软件接入与 Agent

- 日期：2026-08-21
- 版本：1.0.2 开发线
- 结论：通过

## 软件接入

- OpenCode、Pi Coding Agent、OpenClaw、Hermes Agent 与“其他客户端”统一为注册表驱动的摘要行。
- 每个摘要行只显示用户状态和一个推荐动作；版本、路径、协议、配置、断开和凭据说明进入详情抽屉。
- 内置 HAL100 Agent 与用户安装软件的运行边界进入“了解运行边界”抽屉，并只在打开后读取详情查询。
- 四类外部 Agent 继续调用各自的 Rust 适配器；注册表只统一展示，不合并配置格式、所有权或生命周期。

## Agent

- 首屏使用一份“可开始任务/需要处理/运行中”状态摘要；版本、运行策略和内部状态进入技术详情。
- Provider 一级选择只保留本地与云端；云端再选择“仅本次任务”或“当前会话”，发送范围与原生确认仍在操作现场展示。
- 根据当前状态最多展示三个推荐任务；分类任务库保留完整 18 项固定工具能力，自然语言输入仍可到达同一能力。
- 结果区先显示受控计划和回答，工具轨迹、run ID、模型名与内部工具名默认折叠；空状态下的装饰性三步流程已删除。
- 旧的隐藏模板 DOM 已移除，避免视觉隐藏内容继续增加页面负担。

## 安全与验收

- 配置、断开、私有安装、私有卸载和用户安装仍是不同语义；所有写操作继续要求一次性计划与 Rust 原生确认。
- 云端失败不会回退到本地 Qwen；内置 Pi 与外部 Pi 的程序、HOME、会话、凭据和 Usage 身份保持隔离。
- Desktop 23 项测试覆盖统一摘要、抽屉配置、云端范围和 18 项任务库；真实浏览器确认首屏推荐任务不超过三个。
- 迭代总闸门：Agent Kernel 27 项、Rust workspace 228 项、生产构建和真实浏览器回归通过。
