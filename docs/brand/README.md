# HAL100 品牌标志

## 当前标志

HAL100 使用一个简约的正视摄像头机器人：单镜头表达“观察与诊断”，小型底座表达“受控本机 Agent”。标志不包含文字，在小尺寸侧边栏、窗口图标和托盘入口中都保持同一轮廓。

## 颜色

- 暖米白：`#FFF8EF`
