# HAL100 安全设计

当前版本、schema、Agent RPC和工具数量的易变摘要以[当前开发状态](CURRENT_STATE.md)为准；
本文只维护现行安全边界与历史演进说明。

## 1. 安全目标

- 默认只暴露本机回环网关。
- 模型不能直接控制操作系统。
- 任何安装、卸载和删除操作都由用户确认。
- 云端调用必须显式、可预览、可撤回。
- API Key和敏感日志不得进入前端状态、SQLite或源码。
- 外部模型和外部后端默认不视为 HAL100资产。

## 2. 信任边界

以下输入全部不可信：

- OpenCode及通用客户端请求。
- 模型和模型元数据。
- 本地或云端 Agent输出。
- Agent Kernel Sidecar消息、状态和异常。
- 外部后端响应。
- Hugging Face和ModelScope下载内容。
- OpenCode现有配置和日志。
- 用户选择的文件路径和后端 URL。

所有输入必须经过大小、类型、路径、协议和权限校验。

迭代4硬件探测只执行`/usr/sbin/sysctl`和`/bin/df`绝对路径，参数字段为 Rust固定白名单，磁盘目标由 Tauri应用数据目录生成；WebView不能传入程序、系统字段或任意探测路径。模型数据库从首次记录起区分`managed`和`external`，但当前只读目录和默认来源设置不授予任何文件删除或引擎安装权限。

外部GGUF选择使用 Tauri Dialog插件的 Rust API。主 WebView capability只授予原生标题栏拖拽和双击缩放两个窗口命令，不授予 Dialog或文件系统插件命令。专用导入命令拒绝符号链接和非普通文件，验证固定GGUF头并计算完整SHA-256，生成5分钟一次性计划，在原生确认后再次复核路径、快照和完整哈希。确认只写`external`索引和脱敏审计摘要，绝不复制、移动、改写或删除源文件；启动模型前还会再次核对数据库中的独立哈希。

## 3. 网关安全

- 默认只绑定 `127.0.0.1`，不绑定 `0.0.0.0`。
- 本地客户端使用独立凭据。
- 数据库只保存凭据哈希和显示前缀。
- 凭据比较使用恒定时间实现。
- 限制请求头、请求体、并发、空闲连接和生成超时。
- 禁止将 Authorization Header写入日志。
- 后端 URL需防止意外访问本机敏感服务和危险协议。
- 局域网后端允许明示配置，但界面必须显示传输安全状态。

当前边界：Gateway固定绑定IPv4回环地址；健康检查外的入口必须使用Bearer Key；SQLite只保存SHA-256摘要、显示前缀和客户端ID；摘要按固定32字节恒定时间比较。本地Authorization不会转发给后端，后端使用独立凭据。请求正文限制为2 MiB并有15秒读取期限，模型标识最多256字节；非流式响应限制为16 MiB，流式响应限制为64 MiB和16个活动流；后端连接、空闲读取和总生命周期均有期限，同时进入的请求限制为64。Usage由不丢弃已接收记录的专用单写入线程持久化。默认日志过滤器只允许HAL100模块输出Info；请求正文、响应正文、Key和Authorization均不记录。

托管 llama-server不复用公开固定端口：每次启动选择随机回环端口，通过`0600`临时文件装载随机会话Key，认证健康检查通过后删除文件；Gateway使用独立后端Bearer Key，直接访问推理端口会被拒绝。引擎发布清单同时在代码中固定归档和`llama-server`二进制SHA-256，不能信任安装目录内自述哈希。

用户登记的外部后端API Key只写入产品专用系统凭据库；当前SQLite schema v15仍只
保存`credential_id`引用，不保存Key。Rust在启动时读取凭据并构建内存后端配置，前端目录
DTO只包含“凭据是否已配置”，不会返回Key值。Keychain条目缺失、过长、非UTF-8或读取失败
时，对应后端与模型别名不进入运行态。删除外部后端和模型别名必须由Rust发起原生确认；
活动或仍被别名引用的后端拒绝删除。

通用OpenAI/Anthropic客户端使用HAL100生成的独立高熵本地Key。明文只在创建命令成功后的单次响应中进入WebView；SQLite与运行时认证注册表只保存SHA-256摘要、显示前缀和归属ID，后续目录查询无法恢复明文。撤销客户端必须由Rust发起原生确认，并同时移除运行时摘要和数据库所有权；任一步失败都会补偿恢复，避免出现界面已撤销但旧Key仍可用的分裂状态。

本机后端自动发现严格限制在代码固定的IPv4回环目标和用户已保存、由Rust重新验证的后端实例，
不接受WebView传入探测URL，不扫描局域网或端口范围，不读取进程命令行。vLLM固定检查同origin
的版本、健康和OpenAI Models端点；llama.cpp Server通用发现仍只检查固定Models端点。Ollama
由独立只读适配器检查固定`127.0.0.1:11434`，客户端
禁用系统代理，连接超时350毫秒、总超时1秒；版本响应最多64 KiB，模型目录最多4 MiB和4096项。
Ollama模型必须满足`name == model`、受限字符串长度、无控制字符、无重复名称和64位十六进制
摘要，否则目录整体故障关闭。发现结果不包含凭据、路径或生命周期命令；只有用户已保存并启用、
引擎类型和API根地址完全一致且属于正式支持单元的外部后端才能与完整模型证据组成候选。已保存
后端的认证材料由凭据库解析成不可序列化、Debug脱敏的Rust目标，只在禁代理/禁重定向的同origin
请求边界注入。候选本身没有权限；保存时Rust重新实时检查并在schema v15中固定适配器、后端
配置修订、origin指纹、版本、模型、类型化证据和协议能力指纹。预检前漂移直接拒绝，
确认后与切换后再次复检；任何失败恢复旧活动路由与托管状态。桌面更新漂移快照必须经过Rust
原生确认，且不会启动、安装、拉取或切换模型。

MLC LLM官方REST接口当前没有可靠的包版本或设备身份端点，且返回空
`system_fingerprint`。因此其正式资格只接受用户明确选择的绝对本地MLC部署目录，并在阻塞线程中
有界读取固定配置、权重清单、清单声明的全部分片和tokenizer文件，形成部署内容指纹。目录会先
规范化；相对路径、路径穿越、符号链接逃逸、重复或零长度分片、大小不符、读中截断、超过4096个
文件或128 GiB总量均故障关闭。普通目录别名与`HF://`标识仍可发现，但不能保存为可执行方案。
适配器没有目录外枚举、写入、安装、启停或模型拉取权限；内容指纹也不冒充服务未暴露的引擎版本
或实际加速器证明。

MLC工具调用还有一个引擎专属协议差异：官方响应把`function.arguments`返回为对象，而OpenAI
客户端要求JSON字符串。兼容转换只由数据库中Rust验证过的`engine=mlcLlm`后端绑定启用，只处理
有界非流式响应中的单工具参数对象；参数必须仍是对象且转换后响应不得超过原Gateway上限。通用
OpenAI后端不能按URL、模型名或响应内容触发该行为。带工具的MLC流式请求尚无正式合同，Gateway
在发送上游前直接拒绝，避免把未验收的增量形态交给Pi或其他客户端。

## 4. Agent能力模型

Agent只能调用注册过的结构化工具。工具按风险分类：

| 风险 | 示例 | 规则 |
| --- | --- | --- |
| 只读 | 硬件检测、扫描状态、健康检查 | 可自动执行 |
| 可逆 | 启动、停止、普通切换 | 按操作上下文决定是否提示 |
| 安装 | 下载模型、安装托管引擎 | 必须预览并确认 |
| 破坏性 | 卸载、删除、强制切换 | 必须二次确认 |
| 禁止 | 任意 Shell、任意路径删除、关闭系统安全能力 | 无工具入口 |

确认令牌必须：

- 绑定单个用户可见操作。
- 绑定精确参数、目标和版本。
- 有较短有效期。
- 只能使用一次。
- 参数变化后失效。

当前桌面命令除上述一次性计划外，安装引擎、卸载引擎、下载模型、导入模型、修改OpenCode配置、删除外部后端、删除模型别名、撤销通用客户端、按保留策略删除过期数据、强制激活外部后端、强制切换托管模型和强制停止托管引擎还必须经过 Rust发起的原生系统确认窗口；WebView不能自行生成等价的确认结果。数据清理确认绑定同一个截止时间与准确的Usage/审计条数，不会因确认期间时间推进扩大范围。强制路由操作在确认后旋转旧后端请求代次，旧请求只记录`forced_route_switch`，不把用户操作误判为后端故障，也不影响新代请求。

云端 Agent与本地 Agent使用完全相同的 Policy Engine和 Executor。

迭代8同时开放“单次云端”和“当前会话使用云端”，但没有持久化或静默开关。WebView先请求Rust生成发送范围预览；单次预览显示目标、模型、任务字节数和固定数据类别，当前会话预览明确后续任务、系统指令、只读工具结果与“不保存聊天历史”范围。真正发送单次任务或启用当前会话前，Rust再次解析同一目标并显示macOS原生确认。请求只引用现有后端ID和模型ID，不包含API Key。Rust只接受已启用、已载入Gateway、带Keychain引用的OpenAI/Anthropic兼容后端；其他类型、缺失凭据、未载入后端、控制字符或越界标识全部故障关闭。

当前云端会话只在`agent_provider::AgentProviderService`内存保存目标、启用时间和固定错误码，不写SQLite，不保存提示词或回答。启动、退出和任务解析继续由`AgentService`同一运行锁串行化，因此退出成功后不会再有旧会话任务进入。新Provider服务实例默认没有会话，应用重启恢复本地Qwen。后端删除、禁用、失载或提供方认证失败不会清除授权或回退本地；界面持续显示不可用/上次失败状态，后续任务故障关闭，用户可以明确退出。

云端Sidecar只接收临时本机Gateway Key和随机内部模型别名。真实云端Key仍由外部后端管理器从macOS Keychain恢复到Rust Gateway内存，既不进入WebView、Agent RPC、Sidecar环境、SQLite、审计详情或日志，也不会被工具结果返回。临时路由和临时客户端凭据在成功、错误、取消与提前返回时由RAII清理；云端失败不会调用本地Agent运行时。Usage使用`hal100-agent-cloud`独立归属，审计只允许`provider`、`backendId`、`model`、固定错误码和工具数量等白名单字段。

### 4.1 Pi Agent Core隔离规则

Pi Agent Core是编排依赖，不是安全边界。HAL100必须满足：

- Pi运行在按需 Agent Kernel Sidecar中，Rust Core保持唯一执行权威。
- 不嵌入完整 `pi-coding-agent`，不注册其任意 Shell、文件读写或进程工具。
- 不扫描 `~/.pi`、项目 `.pi`、`AGENTS.md`，不加载第三方扩展、Skills或 Prompt Templates。
- HAL100只注册白名单工具代理；代理本身不操作系统，只把请求发送给 Rust Tool Broker。
- Rust按自己的 Schema重新解析每次工具请求，拒绝未知字段、未知工具和越界参数。
- Pi执行前钩子只能提前阻止请求，不能充当最终授权。
- Pi提供的确认 UI或确认结果不构成 HAL100授权；只有 Rust签发的一次性确认令牌有效。
- HAL100只向 Sidecar传入短生命周期的本机 Gateway凭据，不传入云端 API Key或客户端长期 Key，也不在私有 RPC中提供凭据读取能力。
- Sidecar默认不写 Pi会话文件，不继承不必要的环境变量，工作目录固定在 HAL100受控目录。
- Sidecar只运行固定代码和精确锁定的依赖，禁止运行时安装包和动态加载用户代码。
- Sidecar退出、崩溃、协议错误或超时必须故障关闭当前 Agent操作，不能降低工具风险等级或转为直接执行。

当前RPC v13只允许能力注册表中的20个固定工具。OpenCode、Pi Coding Agent、OpenClaw和Hermes Agent共用检测、配置计划、断开计划与受管安装计划入口；Pi另有只针对HAL100私有运行时的卸载计划。模型停止计划只接受同一任务刚读取的当前活动`modelId`，Rust在计划和执行前双重复核，原生确认后仅停止托管进程并保留模型、索引和用量。`integrationId`必须来自固定注册表并与Rust已验证结构化任务的目标一致。受管安装和卸载当前只允许Pi固定配方；卸载要求提示明确指向HAL100私有/受管运行时，且状态明确返回`managedInstallation=true`，不能把断开配置或含糊的用户Pi卸载请求升级为文件操作。全面诊断和部署观测仍只返回有界脱敏状态。`agent.run.start.requiredTools`必须规范有序、无重复、前置闭包完整且最多含一个写计划；Rust和Sidecar共同读取共享策略，未知能力故障关闭。Rust验证精确参数、run ID、tool call ID、唯一性、调用顺序和当前每任务最多4次调用；每个成功工具结果最多128 KiB并由双方校验。配置、断开、安装、私有卸载、模型停止和运行方案切换都只生成外层一次性计划，真正执行要求Rust原生确认。运行方案目录只向Pi提供方案ID、所有权、非秘密后端ID、模型/引擎、适配器变体/合同修订和可选容量，不含API根、digest、路径、命令或凭据；其附带的引擎能力投影只包含静态适配器身份、主机兼容性、支持格、证据进度和推荐理由，同样不含端点、摘要、路径、命令或凭据。Pi只能复制精确`profileId`请求Rust实时预检。外部执行完成后，Rust再次访问引擎并核对版本、模型digest和完整活动路由；Pi不能重验信任快照、控制Ollama生命周期或写入路由。Sidecar仍无通用Shell、包管理器、任意文件读写、Accessibility、Screen Recording或Apple Events能力；npm只由Rust确定性部署执行器以固定绝对路径、固定参数、清空环境、私有工作目录和有界超时调用。

结构化意图提案同样不是安全边界。意图schema v1不允许Pi提交工具名、能力集合、Provider、执行参数、确认状态、授权或自由文本理由；Rust只接受精确字段、20类注册任务、匹配的目标类型和四个固定外部Agent ID。受管安装和移除在Core层只接受Pi目标。RPC v13只在确定性结果为`Unresolved`时调用零工具Pi提案；意图输出最多128 Token且`temperature=0`。Sidecar不转发原始输出，Rust再次校验后执行双路裁决。确定性Shell越权、所有权扩大和歧义规则优先于模型提案，冲突时不选择任一任务。

任务级上下文裁剪不是授权来源。下一工具仍由完整Rust任务和Tool Broker状态决定；模型上下文只
保留直接依赖，配对异常时不裁剪。RPC v13效率载荷只能含数值，Rust复核容量、回合、Usage和
重复量关系；提示词、回答、工具参数和原始结果不进入指标。最终计划后的固定回答不会执行计划，
原生确认、一次消费和现实状态复验保持不变。

上下文容量也不是模型权限。Rust启动时只读一次统一内存，并从版本化合同选择16K基线或32K
标准档；RPC v13显式携带该档案，Sidecar拒绝合同外本地容量。Pi、提示词、远端响应和用户文本
不能请求64K或覆盖Rust选择；容量增加不扩大工具、路径、凭据、文件或执行范围。

迭代35起，可信任务只通过Rust固定的任务到叶能力映射生成`requiredTools`，并由能力注册表闭合前置关系；不与旧关键词工具集合求并集。外部Agent目标取自已验证任务，不取自模型工具参数。确定性守卫不启动Kernel或模型；Pi守卫不进入工具运行；含工具但未解析的请求故障关闭，只有零工具解释保留兼容。开发期`safe-legacy`只回退确定性任务，不能激活Pi独有任务。意图与接管指标均只在进程内保存固定状态、裁决/决策计数和耗时，不含提示词、回答、任务类型、run ID、目标或凭据。接管仍只生成计划，不改变原生确认和确定性执行边界。

迭代36起，可信任务阶段也只由Rust推进。检查点schema v1只公开任务类型、目标类别、期望状态、
Provider类别、数据范围、阶段序列、待确认布尔值、复验状态、恢复范围和更新时间；不包含提示词、
回答、具体资源/目标ID、计划ID、run ID、路径、凭据、工具参数或原始工具结果。任务类型只用于
当前任务状态展示，与仍不含任务类型的聚合接管指标职责分离。检查点和计划均只存在于当前进程；
唯一恢复范围是精确计划仍有效时继续原生确认，重启不会恢复授权。

迭代37起，成功结论同样只由Rust推进。每类任务拥有固定成功谓词和证据来源白名单；工具成功、
执行器摘要、模型回答、Sidecar完成消息和前端状态均不是成功证据。只读结果在Rust持有类型化DTO
时缩减为枚举化结论；确认执行后重新读取精确模型活动态、模型库、引擎、外部Agent接入态、Pi
私有安装态或原修复发现。证据来自错误工作流时拒绝且不推进状态；证据不可用直接阻断。只有动作
首次明确不满足可以在同进程返回规划一次，同一任务第二次仍不满足即进入终态，不能无限重试。

检查点schema v3在成功谓词、证据来源和有界计数之外，只新增澄清种类、尝试数和过期时间，不包含
具体观察内容。Agent专属`agent_action_*`审计只保存固定动作类别、原因或错误码，不保存计划ID、
run ID、具体目标或路径；正常领域操作仍按既有审计所有权记录用户可见结果。证据摘要不写SQLite，
也不发送给Pi。

Pi受管部署不使用全局安装，不申请管理员权限，不修改PATH、HOME、npm prefix、用户Pi配置或已有二进制。部署根目录拒绝符号链接并收紧为`0700`；固定顶层包在执行前后复核Registry元数据，`npm pack`和安装均禁用脚本，归档SRI匹配后才从本地归档进入UUID暂存目录。npm只能在该暂存目录解析本地归档，生成lockfile v3；Rust规范化并验证136项非根包的版本、来源、SRI、依赖、可选依赖、Peer、平台和入口字段，闭包SHA-256必须等于配方固定值，且所有Registry依赖都必须来自固定官方Registry。闭包通过后才允许执行`pi --version`并原子启用；失败只清理该暂存目录。用户候选始终优先于HAL100私有候选，因此私有副本不会冒充或覆盖官方用户安装。

私有卸载与接入断开是两个独立事务。卸载预览先验证运行时不是符号链接、规范路径是HAL100固定子目录、包入口和依赖闭包仍与配方一致；确认执行前再次验证相同快照，再将精确`runtime`原子改名为一次性隔离目录并移入系统废纸篓。废纸篓调用失败且隔离目录仍存在时立即改名恢复；恢复失败返回独立固定错误码。该流程不枚举或操作用户Pi候选、`~/.pi`配置、凭据和会话。

模型发现与下载采用逐步缩权：来源只能读取用户在HAL100设置的默认来源；搜索最多返回8个公开、非gated仓库；仓库检查必须精确命中同任务搜索结果，最多返回12个带可信SHA-256的GGUF；下载计划必须精确命中同任务仓库快照。`ModelDownloadManager`随后重新请求仓库并复验来源、仓库、修订、文件、哈希、空间、重复项和受管目标路径。底层计划ID不发送给Pi，取消确认、新任务、任务取消或失败会废弃未使用计划；只有Rust原生确认后才启动下载，完成哈希与GGUF校验前不会进入模型库。云端Agent最多接收公开目录元数据，不接收本地路径、目标路径、Keychain引用或上游API Key。

诊断报告不是授权令牌。只有Rust标记`repairKind`的确定性发现可以进入修复计划，且计划前重新读取现实状态以关闭陈旧报告竞态：模型索引清理要求文件仍为`Missing`，OpenCode要求已安装且仍为`NotConfigured`，引擎安装要求仍未安装。引擎/模型完整性异常、OpenCode冲突或外部修改、熔断后端不自动修复。执行继续消费5分钟一次性计划并要求Rust原生确认；随后按需复检，复检失败仅记录固定审计码。诊断不扫描原始日志、不执行完整模型哈希、不返回路径，并限制最多64个发现，避免把本机敏感内容或无界数据送入本地/云端Agent上下文。

每次任务创建独立高熵Gateway客户端Key并只保存在内存与私有RPC中；RAII guard在成功、失败和提前返回时从认证注册表移除。Key、提示词、回答和系统路径不进入SQLite、审计、日志或前端状态。Sidecar任务完成后必须确认shutdown并立即退出，单次HOME/TMP目录随guard删除；本地模型运行时在最后一次任务完成后空闲2分钟退出。用户后端管理器拒绝创建、删除或恢复内部别名`hal100-agent`，Agent运行不会替换用户活动后端。

所有Agent变更工具都只能生成计划，不能执行。外层计划在Rust内存中绑定run、精确目标、当前状态、5分钟有效期和原生确认要求，内部确定性管理器计划ID不返回Pi；已有待确认计划不能被静默替换，新任务会先明确废弃旧计划，每个计划只能消费一次。伪造、超长、过期、已消费、与当前任务不匹配或缺少确认标记的计划全部拒绝且不得推进检查点。WebView请求执行时由Rust显示原生确认，确认后再次校验并调用既有确定性管理器；取消确认、新任务、Agent失败、任务取消或状态读取发现过期都会废弃两层计划并审计。执行成功还必须经过Rust复验阶段才能标记任务完成。

模型移除计划按所有权分流：`managed`文件在确认后重新验证路径组件、符号链接、规范路径、文件大小和活动状态，只能移入系统废纸篓；文件缺失时只清理失效索引；`external`只移除索引，永不触碰源文件。引擎生命周期锁覆盖“再次确认未运行到完成移除”的区间，防止模型启动与删除竞态；固定内置Agent模型在计划阶段即拒绝。Agent仍没有失败下载分片清理、外部源文件删除、任意命令或强制切换工具；模型搜索与下载只能走上文的公开目录、可信哈希和原生确认链。

活动Agent任务取消使用Rust持有的原子标记；模型文件SHA-256每1 MiB、健康等待每50 ms、RPC等待和远端目录工具每100 ms检查一次。取消会丢弃进行中的目录HTTP future、终止Sidecar、废弃未使用下载计划、回收临时Key和会话目录并停止Agent模型，不等待网络超时。模型、Sidecar或WebView不能清除取消标记，也不能把取消转为继续执行。真实Qwen验收中，冷启动取消6 ms、推理中取消到回收完成98 ms。

以上是应用层控制，不自动构成操作系统沙箱。未落实平台沙箱时，Sidecar及其依赖仍以当前用户身份运行，应视为受信任供应链代码；被篡改的 Sidecar理论上可能直接使用进程权限访问文件或网络。macOS与未来 Windows的进程权限收缩方案必须单独验证，无法实施时需记录残余风险和补偿控制。

当前补偿控制已经实现：Sidecar只允许规范化后的固定运行时和受控入口；入口及工作目录不得逃出 Workspace；启动前清空全部继承环境，仅设置6个非凭据变量；HOME和 TMPDIR指向单次会话目录；stdin/stdout/stderr使用专用管道。开发期 `sandbox-exec`测试进一步验证外部文件读写、回环网络和任意 `/bin/echo`子进程均被系统拒绝。由于 `sandbox-exec`及 SBPL已弃用且属于私有接口，这项结果只能作为额外防线，Rust Tool Broker仍是唯一权限权威。

### 4.2 Agent私有 RPC

- RPC必须有协议版本、消息类型、请求 ID、大小限制、超时和取消语义。
- Rust只接受当前会话中已声明的 Sidecar进程消息。
- 工具请求和确认必须绑定 Agent会话、工具调用 ID及精确参数摘要。
- 未知消息、重复完成、过期调用和进程重启前的旧调用全部拒绝。
- stdout只承载协议帧；诊断输出使用独立、限量和脱敏的 stderr通道。
- RPC日志不得记录完整模型上下文、工具敏感参数或 Gateway会话凭据。

## 5. 文件所有权与删除

- HAL100下载的文件记录为 `managed`。
- 用户导入的外部文件记录为 `external`。
- 删除 `managed` 模型优先移入废纸篓。
- 删除 `external` 模型默认只删除数据库索引。
- 删除前解析真实规范路径，禁止未解析变量、通配符和宽泛目录。
- 禁止以用户目录、磁盘根目录和应用数据根目录作为递归删除目标。
- 操作完成后记录目标、结果和可恢复性。

## 6. 下载与供应链

- 下载任务记录具体来源、仓库、修订版本和文件。
- 支持断点续传，但完成后必须重新验证最终文件。
- 可获得官方哈希时必须校验；没有官方哈希时保存本地计算值并明确可信等级。
- 推理引擎二进制必须来自允许清单或项目构建流程。
- 执行下载二进制前验证架构、签名/哈希和安装记录。
- 模型权重、引擎和依赖必须登记许可证。
- Pi Agent Core、Pi AI、Sidecar构建工具和传递依赖必须固定精确版本、校验完整性并登记许可证。
- Sidecar不得在运行时下载或执行新 npm包、Pi包、扩展和脚本。

## 7. 凭据管理

- 外部推理后端和云端 API Key存入macOS Keychain，使用不同的产品服务/账户命名空间。
- 未来 Windows使用 Credential Manager。
- 前端只接收凭据存在状态、显示名称和末尾提示，不接收完整密钥。
- 当前没有设置导出入口；未来若新增，导出内容不得包含密钥。
- 日志、错误、崩溃报告和 Agent上下文不得包含密钥。
- OpenCode本地凭据与云端凭据必须分开。

## 8. 云端隐私

默认允许发送：

- 操作系统、架构、CPU/GPU型号。
- 总内存和可用磁盘。
- 引擎名称、版本和脱敏错误类别。
- 用户当前主动提出的问题。

默认禁止发送：

- API Key和 Authorization Header。
- 用户名、主机名、本地 IP。
- 完整本地路径。
- 其他客户端提示词和回答。
- 未选择的日志和文件内容。

云端发送范围启用前必须显示脱敏预览。当前实现中，单次任务逐次经过Rust原生确认；当前会话只在用户确认范围后于本进程内生效，并持续显示状态和明确退出入口。两种模式都禁止静默失败回退。

## 9. OpenCode配置安全

- 修改前验证配置格式。
- 修改内容必须预览和确认。
- 使用同目录临时文件和原子替换。
- 修改前创建时间戳备份。
- 保留未知字段和无关 Provider。
- 不自动改变默认模型。
- 验证失败自动回滚。
- 只删除带 HAL100所有权标记的配置块。
- 预览只显示HAL100计划写入的字段，不回传现有配置正文，避免已有Provider凭据泄露到WebView。
- OpenCode专属Key写入`0600`独立文件，主配置只保存`{file:...}`引用；SQLite只保存摘要和显示前缀。
- 预览计划5分钟过期且只能使用一次；确认后原配置摘要不一致时拒绝写入。
- JSON与JSONC同时存在、符号链接、超大配置、无所有权同名Provider或目标Key文件均故障关闭。

## 10. 日志与审计

- Release/内部测试默认不记录请求正文和响应正文。
- 日志结构化、限量、轮转和脱敏。
- 相同高频错误进行聚合，防止磁盘写入放大。
- 审计事件记录谁、何时、对什么目标、执行什么受控操作及结果。
- 用户可以查看和清除审计数据，但清除同样需要确认。
- 审计页面只接收固定白名单详情；API Key、提示词、回答和完整路径不会进入DTO。
- 保留策略只在用户明确点击后清理过期数据，不存在后台定时删除。
