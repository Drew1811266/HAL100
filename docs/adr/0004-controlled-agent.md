# ADR-0004：受控 HAL100 Agent

- 状态：已接受
- 日期：2026-08-17

## 决策

HAL100内置本地小模型作为领域受限 Agent，并支持用户主动配置云端 OpenAI/Anthropic兼容模型。模型只能提出结构化白名单工具调用；Policy Engine验证后由确定性 Rust Executor执行。

Agent编排内核、Sidecar边界和第三方依赖选择由 [ADR-0006](0006-pi-agent-core.md) 补充定义。

## 原因

- 小模型适合理解自然语言和编排步骤，不适合直接承担系统权限。
- 结构化工具、风险等级和确认令牌可以测试、审计和阻止越权。
- 云端模型能力更强，但不能因此获得更高本地权限。

## 约束

- Agent不作为通用聊天助手。
- 不提供任意 Shell工具。
- 安装、卸载和删除必须由用户确认。
- 云端必须由用户单次或按会话主动开启。
- 云端 API Key只保存在系统凭据库。

## 当前实现校准（2026-08-19）

- 本地Agent使用Qwen3.5-2B Q4_K_M与Pi Agent Core/Pi AI 0.84.2。
- 硬件摘要、脱敏运行目录和OpenCode状态属于只读工具，可自动执行；模型启动/安全切换、模型移除、llama.cpp安装/卸载和OpenCode配置只生成5分钟有效的一次性Rust计划。
- 即使启动/普通切换在通用风险表中属于可逆操作，Agent路径首版仍始终要求Rust原生确认；Pi成功回调或聊天中的同意不是授权。
- 所有可写计划都必须经过Rust原生确认；托管模型只移入系统废纸篓，外部模型只移除索引，内置Agent模型拒绝移除。模型搜索/下载、失败分片清理和强制切换没有Agent入口。
- 活动任务取消由Rust进程外控制，并故障关闭Sidecar、临时凭据和独立Agent模型。
- 迭代8开放单次选择和当前内存会话两种云端范围：前端只引用已配置后端和模型，Rust先生成对应脱敏预览、再显示原生确认并重新校验。会话范围不是聊天历史，只在当前进程内保存目标和固定状态；退出或重启恢复本地默认。
- 云端Sidecar仍只使用短生命周期本机Gateway Key；Gateway从现有macOS Keychain后端配置注入真正上游凭据。OpenAI/Anthropic使用明确协议路径，临时内部路由在任务结束后删除。
- 云端任务以`hal100-agent-cloud`独立统计，不启动本地Qwen；云端错误直接失败，不得回退本地。
- 会话状态变化与任务启动共用Rust运行锁；后端删除、失载或认证失败时保留可见的故障状态并允许明确退出，绝不自动改用本地Provider。
