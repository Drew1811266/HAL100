# ADR-0005：平台、开源与发布范围

- 状态：已接受
- 日期：2026-08-17

## 决策

- 首版及未来 macOS版本只支持 Apple Silicon，不支持 Intel Mac。
- 当前不开发 Windows，但平台接口需为未来 Windows 10/11实现保留边界。
- HAL100自身代码使用 MIT许可证。
- 当前只做内部开发测试，不考虑签名、公证、应用商店和正式发售。
- 开发采用连续开发版迭代，不在每个迭代完成后制作安装包。
- 首版界面仅中文。

## 影响

- 当前构建、Sidecar和性能测试只覆盖 Apple Silicon。
- 不因未实施的 Windows版本拖慢 Mac主线，但不得把 macOS调用写进领域核心。
- 第三方组件与模型权重保留各自许可证并登记清单。
