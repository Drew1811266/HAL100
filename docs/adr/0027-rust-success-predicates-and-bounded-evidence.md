# ADR-0027：Rust成功谓词与有界证据复验

- 状态：已接受
- 日期：2026-08-25
- 关联：ADR-0021、ADR-0025、ADR-0026

## 背景

Core已经为18类Agent任务定义14种`AgentTaskSuccessPredicate`，迭代36也把任务阶段接入真实运行，
但完成路径仍把“必需工具调用成功”或“确定性执行器返回`Ok`”直接映射为`Satisfied`。这不能区分
空目录、写后状态仍未满足和执行成功但现实复验不可用，也使宽泛环境诊断承担了不属于它的模型、
引擎和外部Agent状态证明职责。

保存原始工具结果用于稍后判断会扩大隐私面；让模型根据回答声明完成又会把概率输出变成状态
事实。无界自动重试还可能重复生成计划、反复要求确认或对同一配置执行多次写入。

## 决策

1. `AgentTaskSpec`继续从Rust工作流取得成功谓词，并为每类任务定义固定证据来源白名单。证据
   来自其他工作流时，任务状态不得推进。
2. Desktop新增`agent_task_evidence`边界。工具持有类型化DTO时立即把相关事实缩减为
   `Satisfied`、`Unsatisfied`或`EvidenceUnavailable`以及一个固定来源枚举和单字节观察计数；
   不在运行态保存原始结果。
3. 只读系统、运行时、诊断、运维历史、短时健康、公开目录、仓库和外部Agent检查分别使用其
   类型化结果。空模型搜索明确为不满足；健康诊断、存在可修复发现和无足够修复证据分别产生
   三种不同结论。
4. 已确认动作执行后进行动作专属复验：模型启动读取精确活动模型和引擎运行态；模型移除重新
   读取模型库；引擎安装/移除重新读取安装态；配置/断开重新检测目标适配器；Pi私有安装/移除
   重新验证受管入口；诊断修复重新查找同一发现的稳定身份。执行器摘要和宽泛诊断不能替代这些
   事实。
5. 幂等受控任务可以在前置类型化状态已经满足谓词时无计划完成。该豁免由Rust证据驱动，不能
   由Sidecar少调用工具或回答文字触发。
6. 只读不满足和所有证据不可用直接进入`Blocked`。受控动作第一次明确不满足可以从
   `Verifying`返回`Planning`，`max_replan_attempts`固定为1；同一精确任务可以继续这一轮，第二
   次仍不满足进入`Blocked`。应用不自动重放提示词、工具或确认。
7. `AgentTaskCheckpoint`升级为schema v2，增加成功谓词、证据来源、观察数、重规划次数与上限；
   复验状态增加`Unsatisfied`和`EvidenceUnavailable`。检查点仍不持久化，也不包含具体目标、
   计划/run ID、路径、凭据、提示词、回答或工具结果。
8. Agent专属`agent_action_*`审计只保存固定动作类别、原因或错误码，不保存计划授权、运行ID、
   具体目标或路径。正常领域管理器仍按既有产品审计规则保存用户可见操作结果；证据摘要本身不
   写SQLite。
9. 本轮不升级Agent RPC v10、不增加18项工具、不修改SQLite schema v9，也不改变原生确认、
   所有权或确定性执行边界。

## 结果

- “模型回答完成”“工具调用成功”“执行器没有报错”和“目标现实状态满足”成为四个不同概念。
- 每类任务只接受可证明其谓词的有界事实；测试可以注入不满足、缺失和错误来源而不伪造原始
  工具内容。
- 一次受控重规划允许从现实偏差恢复，同时防止无限重试和重复确认循环。
- 前端可以解释当前证据结论和来源，但不能修改结论或取得更多授权。

## 未选择方案

- 保存完整工具结果或任务上下文：扩大持久化隐私面，且不是判断当前现实状态的可靠方式。
- 让模型输出置信度或“完成”字段：概率文本不能成为配置成功事实源。
- 所有动作只运行一次环境诊断：诊断粒度不足以证明精确模型、引擎和集成状态。
- 自动无限重试：可能重复写入、确认和远端请求，无法给出稳定终态。
- 任何不满足都立即失败：会丢失一次安全、显式、同任务重新规划的恢复机会。

## 范围说明

本决策只完善开发期Pi任务成功语义、复验和用户可解释状态，不涉及签名、公证、安装包、自动
更新、正式升级或正式发布流程。
