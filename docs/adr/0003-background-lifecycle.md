# ADR-0003：后台生命周期与进程模型

- 状态：部分被 ADR-0009替代
- 日期：2026-08-17

## 决策

首版由 Tauri Rust Core长期驻留，不引入独立系统守护进程。Agent和用户推理运行时均为按需子进程。

原决策要求关闭窗口时销毁 WebView。迭代1压力回归发现 macOS WebKit反复销毁/重建存在进程内资源增长，该部分已由 [ADR-0009](0009-main-webview-reuse.md)替代为“主 WebView创建后隐藏复用”。

## 原因

- WebView、Agent模型和用户模型是主要资源来源，不应无条件常驻。
- 单独系统服务会过早引入跨平台 IPC、更新同步和数据库所有权复杂度。
- 将 Core保持为独立 Rust库，为未来提取后台服务保留路径。

## 默认策略

- 登录启动首次询问，默认关闭。
- Agent空闲两分钟卸载。
- 托管用户模型空闲15分钟卸载。
- 请求明细保留90天，每日汇总长期保留。
