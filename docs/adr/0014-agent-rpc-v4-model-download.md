# ADR-0014：Agent RPC v4 与受控模型下载能力

- 状态：已接受
- 日期：2026-08-20
- 关系：落实 ADR-0013 的能力集合演进方向；补充 ADR-0004、ADR-0007 与 ADR-0011；不改变 Gateway 数据面、SQLite schema v7 或 Tauri IPC

## 背景

迭代12已经把Agent的长期扩展单位从散落工具改为统一能力，但RPC v3仍为每个工具保留一个`requires_*`布尔字段。继续加入模型搜索、仓库检查和下载计划会让Rust与Sidecar契约横向增长，并重复表达能力注册表已有的顺序和前置关系。

HAL100现有模型生命周期已经拥有远端目录和`ModelDownloadManager`：公开仓库限制、精确GGUF路径、固定修订、可信SHA-256、空间余量、重复下载拒绝、5分钟一次性计划、确认时空间复验、临时文件校验和原子安装。Agent不应创建第二套目录或下载实现，只应通过受控应用能力复用这些事实状态所有者。

## 决策

### 1. 私有协议升级到RPC v4

`agent.run.start`使用有序`requiredTools`集合替代RPC v3的十个逐工具布尔字段。Rust从能力注册表生成规范顺序；Sidecar独立验证：名称全部已注册、无重复、顺序规范、前置能力闭包完整、最多4项、最多一个写计划能力。任何不一致均故障关闭。

精确13项工具策略存放在`contracts/agent-rpc/v4-tools.json`，包含当前任务预算、顺序、读/计划效果、前置关系、原生确认和参数正反例，Rust与TypeScript测试共同读取。成功工具结果另有128 KiB预算，必须低于1 MiB帧上限。协议版本变更只影响私有Rust↔Sidecar边界，不改变Tauri命令、Gateway协议或数据库。最多4项是RPC v4的版本化单任务复杂度预算，不是模块或产品能力上限；出现合理的更长工作流时应显式调整策略或升级协议，而不是拆散业务语义迁就数字。

### 2. 新增三个纵向能力

| 能力 | 输入 | 结果与边界 |
| --- | --- | --- |
| 搜索模型目录 | 2—100字符搜索词 | Rust使用用户已选择的默认来源；只返回最多8个公开、非gated仓库摘要 |
| 检查模型仓库 | 搜索结果中的精确`owner/name` | Rust重新读取仓库；只返回最多12个带可信SHA-256的GGUF |
| 生成下载计划 | 仓库快照中的精确相对路径 | 复用`ModelDownloadManager`重新拉取并绑定来源、仓库、修订、文件、哈希、空间和目标路径；只生成计划 |

后一步只能引用同一run中前一步返回的精确值。Sidecar和模型不能选择下载来源，不能传本地目标路径，不能绕过公开仓库、哈希、空间或重复项检查。

远端目录响应继续受4 MiB HTTP上限约束，同时对展示名称、许可证、修订和远端路径设置业务字段边界。Agent目录工具通过100毫秒取消探针等待异步HTTP future；任务取消会丢弃future，不等待15秒请求超时。目录和下载管理器允许应用组合根注入经过同等URL、超时、重定向和响应策略验证的显式端点，以便本地模拟服务完成无公网纵向验收；产品组合仍只使用官方端点构造器。

### 3. 执行仍在Rust原生确认之后

公开Agent计划只暴露用户确认所需的来源、仓库、修订、文件、大小、SHA-256和空间信息；底层下载计划ID不发送给Pi。Tauri显示原生确认后，Rust一次性取走外层计划，再由同一个`ModelDownloadManager`复验空间并启动下载。取消确认、新任务、任务取消或失败会废弃底层未使用计划。

浏览器预览不运行Agent、不启动下载，也不模拟成功结果。云端Agent可能接收公开目录元数据，但不会接收本地路径、下载目标、凭据或后端API Key。

## 后果

- 新能力可以通过能力注册表和`requiredTools`扩展，不再增加逐工具协议字段。
- 模型生命周期仍是下载规则和状态的唯一事实源，Agent只拥有工作流和一次性授权衔接。
- 有界结果会舍弃长尾搜索项和大量文件；用户可修改搜索词或使用模型库完整界面继续操作。
- RPC v4不兼容v3，桌面与Sidecar必须作为同一版本交付；共享清单和帧版本测试负责阻止错配。
- 本地模拟验收可以覆盖搜索、同任务引用、计划、确认和真实下载管理器安装，不需要把公网波动变成默认测试依赖。

## 非目标

- 不支持私有、gated或需要登录的模型仓库。
- 不让Agent暂停、恢复或取消既有下载。
- 不改变模型文件格式校验、数据库schema、Gateway热路径或模型库现有IPC。
- 不处理签名、公证、安装包、发售或正式分发。
