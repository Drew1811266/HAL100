# ADR-0001：桌面与核心技术栈

- 状态：已接受
- 日期：2026-08-17

## 决策

HAL100使用 Tauri 2作为桌面容器、React + TypeScript + Vite作为界面、Rust作为领域与系统核心、SQLite作为本地持久化。

## 原因

- Rust适合长期后台、异步网关、进程管理和明确的安全边界。
- Tauri允许 UI和 Rust Core分离，并可在关闭可见窗口后保留后台核心。
- React用于构建标准化桌面界面，但不承担长期事实状态和系统权限。
- SQLite适合本地请求明细、聚合、迁移和离线查询。

## 约束

- 前端不能直接访问敏感系统能力。
- `hal100-core` 必须保持可独立测试，避免业务逻辑绑定 Tauri。
- 平台差异只能通过明确接口进入领域核心。
