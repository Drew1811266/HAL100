# ADR-0024：确定性Pi意图质量与脱敏影子观测

- 状态：已接受
- 日期：2026-08-25
- 关联：ADR-0021、ADR-0022、ADR-0023

## 背景

迭代33已经让Pi在确定性入口无法解析时提出结构化意图，但当时只验证协议和裁决规则，尚未
证明内置2B模型对长尾中文表达的质量和方差。旧确定性入口还会把“出现已知外部Agent名称但
动作未知”的请求默认为检查，减少了Pi真正处理长尾表达的机会，也可能造成错误语义。

进入任何受控接管之前，需要先修正这个基线、建立可重复的真实模型合同，并提供不保存用户
内容的产品内观测。观测本身不能扩大Pi权限或成为新的持久化数据面。

## 决策

1. 外部Agent只有出现明确检查语义或已支持动作时才由确定性入口形成任务。已知目标但动作
   未识别时返回`Unresolved`，按需请求Pi；未知目标仍不得形成任务。
2. HAL100受管安装和移除在Core层只允许`pi-coding-agent`目标。模型提示、提案校验和工作流
   注册表都不能放宽该所有权约束。
3. Pi意图调用使用专用模型设置：不注册工具，`temperature=0`，最多128输出Token，并使用
   简短的任务域名称映射与正反例。Sidecar的精确JSON解析、字段白名单和2 KiB输入边界不放宽。
4. `AgentStatus`公开进程内`AgentIntentShadowMetrics`，只聚合提案状态、裁决结果、调用计数和
   毫秒耗时。指标不包含提示词、回答、原始提案、run ID、任务目标、路径或凭据；不写数据库、
   审计正文或日志，应用重启后清空。
5. 新增显式真实模型v3合同：6个确定性入口故意未解析的场景各运行3次，门槛为结构化提案率
   不低于95%、语义精确率不低于85%、安全拒绝率100%、未授权系统变更为0。该测试不进入日常
   快速门禁，需在具备已校验本地模型的环境中显式运行。
6. 迭代34继续保持影子模式。真实模型通过合同只是后续受控接管的必要证据，不授权提案改变
   `requiredTools`、计划、确认、执行器或用户可见回答。

## 结果

- 明确任务继续走零额外模型回合的快速路径，Pi专注确定性规则未覆盖的长尾表达。
- 真实Qwen3.5-2B在当前6场景各3轮中达到18/18结构化、18/18语义精确和6/6安全拒绝；热模型
  意图请求p95与最大延迟约2.61秒。
- 运维和后续迭代可以从Agent状态读取聚合质量信号，而不会建立提示词或回答存储。
- 这组固定场景不能代表开放输入100%准确；受控接管仍需独立的回退、冲突和用户可见行为设计。

## 未选择方案

- 继续把所有已知外部Agent的未知动作默认为检查：掩盖长尾请求并产生错误语义。
- 通过放宽JSON解析提高结构化率：扩大不可信模型输出面，降低协议确定性。
- 保存提示词、回答或原始提案以便调试：与默认不保存用户内容的产品边界冲突。
- 复用通用Agent任务的768 Token和采样设置：对有界分类任务增加方差、延迟和无关输出。
- 将一次真实模型绿灯直接视为接管授权：样本范围和方差证据不足，且缺少独立回退设计。

## 范围说明

本决策只涉及Pi意图质量、确定性路由和进程内影子观测，不涉及签名、公证、安装包、自动
更新、正式升级或正式发布流程。
