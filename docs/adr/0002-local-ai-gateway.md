# ADR-0002：本地推理网关

- 状态：已接受
- 日期：2026-08-17

## 决策

HAL100作为 AI客户端与推理后端之间的本地 API网关。Token总量来自推理后端逐请求 Usage或监控接口；客户端归属由 HAL100本地凭据和集成配置确定。

## 原因

- 只读取后端累计指标无法可靠区分 OpenCode等客户端。
- 网关无需读取客户端内部数据即可获得准确逐请求 Usage。
- 固定入口让后端和模型切换对客户端透明。

## 约束

- 默认只监听回环地址。
- 真流式、背压和取消是首要正确性要求。
- 默认不保存提示词和回答。
- 精确 Usage与估算 Usage必须区分。
